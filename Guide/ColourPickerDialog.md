### Using the Windows Colour Picker Dialog window

There are two ways to select a colour using the Colour Picker dialog, the left-hand side consists of a grid with each cell representing a different colour (blue box in Figure 6a). To select one of these, click on its cell press __OK__ (black line in Figure 6a). Alternatively, on the right hand side is a picture box (blue box in Figure 1b) displaying a 'rainbow', click on this image to select the colour drawn at the tip of the cursor and then set the colour's brightness using the slider (Green box in Figure 6b) to the right of the picture box. The selected colour will then appear in the box (red box in Figure 1b) just below the picture box. To select this colour press the __Add to Custom Colours__ button (black line in Figure 1b) and then press the __OK__ button (Grey line in Figure 1b).

Figure 1a: Clicking on a colour in the grid (blue box) and then pressing __OK__ (black line) will select a predefined colour.

Pressing the __Add to Custom Colours__ button (black line) and then the __OK__ button (grey line) will select the colour and close the window.

Pressing the __Accept___ button will accept the modifications and redraw the image (Figure 2), while pressing __Cancel__ will discard the changes.
