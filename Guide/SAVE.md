# Saving an image to file

![Figure 1](images/figureSave.jpg)

Figure 1: The __Save__ tab.

---

The __Save__ tab of the ___mRNA Display Options___ window allows the image to be saved to a file at a range of resolutions from 96 to 900 DPI (Figure 1).


![Figure 2](images/FigureSave1.jpg)

Figure 2: The DPI of the saved image is set using the dropdown list at the top of the __Save__ Tab (blue line). This allows the DPI to be set at 96, 200, 300, 400, 500, 600, 700, 800, or 900. Pressing the __Save__ button (black line) will prompt you to enter a file name and location before saving the images as a bitmap, portable graphic, JPEG, or TIFF image file.

---

![Figure 3](images/figureSave2.jpg)

Figure 3: An exported image at 300 DPI. This image may appear fuzzy because it has likely been downsampled by your browser. To appreciate the fine details, download the image and view it in an application such as Paint, GIMP, or Photoshop.
