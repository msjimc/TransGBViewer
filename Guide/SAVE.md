## Saving an image to file

![Figure 1](images/figureSave.jpg)

The __Save__ tab of the ___mRNA Display Options___ window allows the image to be saved to file in a range of DPIs from 96 to 900 DPIs (Figure 1).


![Figure 2](images/FigureSave1.jpg)

Figure 2: The DPI of the saved image is set using the dropdown list at the top of the __Save__ Tab (Blue line). this allows the the DPI to be set at 96, 200, 300, 400, 500, 600, 700, 800 or 900.
