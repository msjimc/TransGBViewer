# Adjusting the order data flow

![Figure 1](images/figureLayout1.jpg)

The __Layout__ tab of the ___mRNA Display Options___ window allows the order of the layout to be changed as well as the order and names of the transcripts (Figure 1).

<hr />

In the pervious tabs it was possible to create an image that displays the aligned transcript sequences as well as metadata from the GenBank sequence files and data downloaded from the Uniprot and InterproScan websites. By default, the order is:

- coordinate axis label (blue box in Figure 2)
- the aligned transcripts (black box in Figure 2) 
- GenBank file metadata (green box in Figure 2)
- UniProt features (red box in Figure 2)
- InterProScan features (grey box in Figure 2)

![Figure 2](images/figureLayout2.jpg)

Figure 2: The default layout order of the data blocks

## Changing the order of the feature classes of the image

<b>Note:</b> The grid contains all the feature class names irrespective of whether they are present in the image.

The __Feature class order__ panel of the __Layout__ tab contains a grid containing the names of each of the feature classes (blue box in Figure 3). Is one of the names is selected, it is possible to change is position relative to the other features using the two buttons to the left of the grid (red and green boxes in figure 3) 

![Figure 3](images/figureLayout3.jpg)

Figure 3: The order of a class of features can be changed by selecting it in the grid (blue box) and then pressing the Up (red box) or Down (green box) buttons. 

<hr />

Selecting the Interval markers feature name and pressing the down arrow button mores the __Interval markers__ name one place down the list in the grid (black line in Figure 4) and also moves the interval marker label below the transcripts (blue box Figure 4)

![Figure 4](images/figureLayout4.jpg)

Figure 4: Selecting a features class name in the grid (black line) and pressing one of the arrow buttons moves the selected feature class name relative to the other names in both the grid and the image (blue box).
