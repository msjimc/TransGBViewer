# TransGBViewer Guide

__TransGBViewer's__ user interface consists of two windows: the __mRNA Display Options__ window and the __Sequence Display__ window (Figure 1).

![Figure 1](images/figure1.jpg)

Figure 1: The dual windows of __TransGBViewer__

<hr/>

The __mRNA Display Options__ window contains controls organised across seven tab pages that are used to modify the image that is displayed in the __Sequence Display__. Initially, the  __Sequence Display__ is blank, and the __mRNA Display Options__ displays the options for importing data.

## Importing GenBank sequence data

The __Import__ tab of the  __mRNA Display Options__ window allows GenBank-formatted sequence and metadata to be imported: 
 - [Importing data](DATA.md/#importing-sequence-data)

## Formatting the Image

The __Format__ tab of the  __mRNA Display Options__ window allows the basic format of the image to be modified: 
 - [Adjusting the image's format](FORMAT.md/#the-format-tab-adjusting-the-images-format)

 ## Modifying how sequences are displayed

 The __Display__ tab of the  __mRNA Display Options__ window allows the way sequences are displayed to be modified: 
 - [Adjusting the sequence display](DISPLAY.md/#adjusting-how-sequences-are-displayed)

 ## Annotating sequences with data from the GenBank, UniProt and InterProScan websites

 The __Feature__ tab of the  __mRNA Display Options__ window allows metadata from the GenBank files and the UniProt and InterProScan websites to be included in the image: 
 - [Annotate the image with metadata](FEATURES.md/#adding-metadata-to-displayed-transcripts)

 ## Adjust the order of the different types of data

  The __Layout__ tab of the  __mRNA Display Options__ window controls the order in which interval coordinates, transcript sequences, and GenBank, UniProt, and InterProScan features are drawn: 

 - [Set the image's layout](LAYOUT.md\#adjusting-the-order-of-each-class-of-features)

## Highlight the location of sequences of interest

  The __Sequence__ tab of the  __mRNA Display Options__ allows the location of sequences of interest such as anti-sense RNA or siRNA binding sites to be shown: 

 - [Display the location of sequences of interest](SequencesOfInterest.md\#highlighting-the-location-of-dna-sequences-of-interest)

## Add markers to highlight specific features

The __Markers__ tab of the __mRNA Display Options__ window allows symbols and markers to be added to the image to aid its description:

- [Add markers to highlight features](MARKERS.md\#manually-annotating-the-transcripts-and-features-in-the-image)

## Save the image to a file
The __Save__ tab of the __mRNA Display Options__ window allows the image to be saved at a range of resolutions from 96 to 900 DPI.

- [Save the image](SAVE.md\#saving-an-image-to-file)
