# TransGBViewer Guide

___TransGBViewer's___ user interface consists of two windows: the ___mRNA Display Options___ window and the ___Sequence Display___ window (Figure 1).

![Figure 1](images/figure1.jpg)

Figure 1: The dual windows of ___TransGBViewer___

<hr/>

The ___mRNA Display Options___ contains controls placed across 7 tab pages that are used to modify the image which is displayed in the ___Sequence Display___. Initially, the  ___Sequence Display___ is blank and the ___mRNA Display Options___ displays the options for importing data.

## Importing GenBank sequence data

The __Import__ tab of the  ___mRNA Display Options___ window allows GenBank formatted sequence and meta data to be imported : 
 - [Importing data](DATA.md)

## Formatting the Image

The __Format__ tab of the  ___mRNA Display Options___ window allows the basic format of the image to be modified: 
 - [Adjusting the image's format](FORMAT.md)

 ## Modifying how sequences are Displayed

 The __Display__ tab of the  ___mRNA Display Options___ window allows the way sequences are displayed to be modified: 
 - [Adjusting the sequences's display](DISPLAY.md)

 ## Annotating the sequences with data from the Genbank files, the UniProt and InterProScan websites

 The __Feature__ tab of the  ___mRNA Display Options___ window allows meta-data from the GenBank files and the UniProt and InterProScan websites to be included in the image: 
 - [Annotate the image with meta data](FEATURES.md)

 ## Adjust the order of different types of data

  The __Layout__ tab of the  ___mRNA Display Options___ window allows order in which the interval cordinates, transcript sequences, and genBank, Uniprot and InterProScan features are drawn: 
 - [Set the image's layout](LAYOUT.md)

## Add markers to highlight specific features

The __Markers__ tab of the ___mRNA Display Options___ window allows symbols and markers to be added to the image to aid is description:

    - [Add markers to highlight features](FEATURES.md)

## Save the Image to file
The __Save__ tab of the ___mRNA Display Options___ window allows the image to be saved in a range of DPIs from 96 to 900 DPIs.

    -[Save the image](SAVE.md)
